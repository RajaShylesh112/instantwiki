## Component Naming Convention

**Format:** `[type]-[number]`

Examples:
- `btn-001` (Action Button)
- `inp-001` (Input Field)
- `crd-001` (Card Container)
- `drw-001` (Slide-out Drawer Sheet)

## Component File Structure

Each component markdown file includes:
- Component ID & Title
- Type and purpose
- Style Tokens mapping
- Visual states table
- Usage tracking (which page specs import this component)
