# Concept Graph Canvas [gra-001]

**Type:** Interactive
**Category:** Visual Concept Map
**Purpose:** Render forces-directed network graph of wiki concepts, supporting zoom/pan and node click navigation

---

## Overview

The Concept Graph Canvas renders extracted concepts as node circles and relationships as connecting edges. It serves both as a landing preview widget and a full-screen explore tool.

---

## Variants

- **Mini Card Preview:** Static or semi-interactive rendering inside a small card element.
- **Full Screen Canvas:** Full bleed interactive SVG/Canvas viewport with zoom, pan, search, and float panel overlays.

---

## States

**Required States:**
- **Default:** Renders complete graph centered on viewport.
- **Hover Node:** Node glows, radius scales up by 2px, and cursor changes to grab/pointer. Connected edges highlight in accent color.
- **Selected Node:** Canvas focuses and centers on selected node. Popup summary overlay is displayed. Unconnected nodes fade to 20% opacity.

---

## Styling

### Visual Properties

**Size:** Dynamic (100% of container width/height).
**Colors:**
- Nodes: Muted neutral gray or subtle primary border (`hsl(0, 0%, 90%)`)
- Highlight Accent: `hsl(250, 43%, 48%)` (Indigo-600)
- Faded node opacity: `0.2`

## Behavior

### Interactions

**Drag Canvas:** Pans the viewport coordinates.
**Wheel / Pinch:** Zooms in/out within scale boundary (0.5x to 3.0x).
**Click Node:** Activates selected node state and displays overlay popup.
