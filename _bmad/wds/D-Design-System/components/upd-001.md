# Source Uploader Dropzone [upd-001]

**Type:** Form / Input
**Category:** File Uploader
**Purpose:** Handle drag-and-drop file imports and web page URL extractions

---

## Overview

The Source Uploader provides a dashed rectangular drop zone where users drag PDF, TXT, or MD documents. It includes a text field below it to accept direct URL imports.

---

## States

**Required States:**
- **Default:** Dashed gray border, prompt texts active.
- **Drag Over:** Border transitions to solid primary color, backdrop changes to light gray-100.
- **Uploading:** Shows upload progress bar or spinner.
- **Success:** Displays checkmark, resets uploader state.
- **Error:** Displays warning text ("File size too large" or "Unsupported file type").

---

## Styling

### Visual Properties

**Size:** Width 100%, min-height 250px (standalone uploader) or 120px (inline uploader).
**Colors:**
- Default Border: `hsl(0, 0%, 90%)` (dashed)
- Active Border: `hsl(250, 43%, 48%)`
- Background: `hsl(0, 0%, 98%)`
