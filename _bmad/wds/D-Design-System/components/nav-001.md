# Navigation Sidebar [nav-001]

**Type:** Navigation
**Category:** Layout Navigation
**Purpose:** Manage workspace navigation links and profile plan metadata

---

## Overview

The Navigation Sidebar sits on the left side of the dashboard and wiki workspace views, serving as the primary router. It separates branding, main links, and user profile metadata with light border dividers.

---

## Variants

- **Dashboard Variant:** Lists general routes (Dashboard, My Wikis, Usage, Settings).
- **Wiki Variant:** Lists wiki-specific pages (Overview, Pages, Graph, Sources, Settings).

---

## States

**Required States:**
- **Default:** Normal navigation links showing default text colors.
- **Hover:** Active link highlights light gray background and shifts text dark.
- **Active:** Current page link highlighted with subtle left border indicator or solid text accent.
- **Disabled:** Used during processing animations on wiki workspace routes (prevents user navigation).

---

## Styling

### Visual Properties

**Size:** Width 240px, full height (`h-screen`).
**Shape:** Square border on right side (`border-r 1px solid gray-200`).
**Colors:**
- Background: `hsl(0, 0%, 98%)` (gray-50)
- Text: `hsl(0, 0%, 45%)` (gray-500)
- Active Text: `hsl(0, 0%, 9%)` (gray-900)
- Divider: `hsl(0, 0%, 90%)` (gray-200)

## Behavior

### Interactions

**Click:**
Triggers React router / Next.js navigation actions.

**Hover:**
- Shifts item background to `hsl(0, 0%, 95%)`.
- Changes cursor to pointer.
